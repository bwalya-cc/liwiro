# Skill: API Documentation Generation

## Purpose
Turn route definitions and service behavior into clear API documentation.

## Best-Suited Agent
Nzou

## Inputs
- endpoints
- request and response examples
- auth notes
- error models
- versioning notes

## Procedure
1. Group endpoints logically.
2. Describe purpose and usage clearly.
3. Capture request and response shapes.
4. Document auth and error behavior.
5. Flag missing examples or ambiguity.
6. Produce structured docs.

## Output Format
- Overview
- Authentication
- Endpoint Sections
- Error Handling
- Notes and Caveats

## Quality Bar
A developer unfamiliar with the service should be able to understand and use it.

# Skill: Integration Planning

## Purpose
Design a practical integration approach between services or external systems.

## Best-Suited Agent
Kalulu

## Inputs
- source and target systems
- data to exchange
- auth requirements
- latency and consistency expectations
- operational constraints

## Procedure
1. Define the integration objective.
2. Determine request-response versus asynchronous patterns.
3. Identify ownership and source of truth.
4. Review security, retries, and idempotency needs.
5. Define failure handling.
6. Define observability points.
7. Recommend phased implementation steps.

## Output Format
- Integration Objective
- Recommended Pattern
- Risks
- Required Contracts
- Operational Considerations
- Implementation Steps

## Quality Bar
The plan must be implementable, observable, and robust against known failure patterns.

# Skill: Security Hygiene Check

## Purpose
Review operational security basics that affect service integrity and safe deployment.

## Best-Suited Agent
Ntiili

## Inputs
- auth model
- secret handling notes
- environment controls
- logging and access practices
- deployment process summary

## Procedure
1. Review credential and secret handling.
2. Check environment separation.
3. Review access boundaries.
4. Review logging exposure risk.
5. Check baseline hardening practices.
6. Highlight operationally significant weaknesses.

## Output Format
- Security Hygiene Summary
- Notable Risks
- Missing Controls
- Recommended Improvements

## Quality Bar
The review must focus on practical, high-impact weaknesses, not generic fearmongering.

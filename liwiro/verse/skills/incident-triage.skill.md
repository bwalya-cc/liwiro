# Skill: Incident Triage

## Purpose
Summarize a live or recent incident, narrow likely causes, and suggest next investigation steps.

## Best-Suited Agent
Ntiili

## Inputs
- symptoms
- logs or alert summaries
- impacted services
- time window
- recent changes

## Procedure
1. Define the incident symptoms and scope.
2. Identify the first reliable signals.
3. Separate symptoms from possible causes.
4. Review recent changes and dependencies.
5. Suggest immediate containment steps.
6. Suggest deeper investigation paths.
7. Record uncertainties.

## Output Format
- Incident Summary
- Scope
- Likely Cause Areas
- Immediate Mitigations
- Next Checks
- Open Questions

## Quality Bar
The output must help a team move faster without overstating certainty.

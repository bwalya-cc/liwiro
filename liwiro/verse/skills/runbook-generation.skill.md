# Skill: Runbook Generation

## Purpose
Create a clear operational runbook for recurring procedures or incident response.

## Best-Suited Agent
Nzou

## Inputs
- procedure or incident pattern
- required tools
- trigger conditions
- escalation paths
- recovery notes

## Procedure
1. Define purpose and scope.
2. Identify triggers and prerequisites.
3. Write step-by-step actions.
4. Include validation checks and exit conditions.
5. Add escalation and fallback guidance.
6. Highlight risks and common mistakes.

## Output Format
- Purpose
- Scope
- Preconditions
- Steps
- Validation
- Escalation
- Notes

## Quality Bar
The runbook must be usable under pressure by someone who did not write it.

# Skill: Observability Review

## Purpose
Evaluate whether a service has adequate logs, metrics, tracing, and alerting for safe operation.

## Best-Suited Agent
Ntiili

## Inputs
- monitoring setup
- log patterns
- metric inventory
- alert rules
- critical user flows

## Procedure
1. Identify critical flows and risks.
2. Review available logs, metrics, traces, and alerts.
3. Check whether failures can be detected and diagnosed.
4. Identify blind spots.
5. Recommend minimal and high-value improvements.

## Output Format
- Coverage Summary
- Blind Spots
- Missing Signals
- Recommended Improvements

## Quality Bar
The review should make it easier to detect, understand, and recover from failures.

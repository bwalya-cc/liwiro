# Skill: Release Notes Drafting

## Purpose
Summarize changes, risks, and impact for a service release.

## Best-Suited Agent
Nzou

## Inputs
- change list
- fixes and features
- known issues
- deployment notes
- affected services

## Procedure
1. Group changes by type.
2. Describe user-visible and operational impact.
3. Note important migration or compatibility issues.
4. Record known issues.
5. Keep the document concise and factual.

## Output Format
- Release Summary
- Added
- Changed
- Fixed
- Known Issues
- Operational Notes

## Quality Bar
Release notes should be clear to both technical readers and stakeholders tracking change.

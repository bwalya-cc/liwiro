# Skill: Schema Contract Review

## Purpose
Review schemas and data contracts for clarity, consistency, and change safety.

## Best-Suited Agent
Kalulu

## Inputs
- schema definitions
- field semantics
- ownership notes
- backward compatibility expectations

## Procedure
1. Review naming and type consistency.
2. Check optional versus required field logic.
3. Identify semantic ambiguity.
4. Review compatibility and versioning assumptions.
5. Highlight validation and integrity concerns.
6. Recommend contract improvements.

## Output Format
- Schema Summary
- Contract Risks
- Compatibility Concerns
- Recommended Changes

## Quality Bar
The review must reduce ambiguity and breaking-change risk.

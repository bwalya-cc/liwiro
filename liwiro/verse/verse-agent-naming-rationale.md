# Verse Agent Naming Rationale

The Verse agents are named from African folklore and regional animal naming traditions so they feel memorable, grounded, and distinct while still matching each agent’s role and personality. The goal is to give each agent a clear symbolic identity rooted in African narrative and linguistic traditions rather than generic technology branding.

## Agent Set

- **Kalulu** for the **Liwiro Architect**
- **Ananse** for the **Liwiro Analyst**
- **Nzou** for the **Liwiro Documentation Advisor**
- **Ntiili** for the **Liwiro Reliability Advisor**
- **Dage** for the **Liwiro Compliance Advisor**

## Rationale

### Kalulu
Kalulu was chosen for the Liwiro Architect. In Tumbuka and broader southern African folktale traditions, Kalulu is the hare, a recurring clever and strategic trickster figure. That makes the name a strong fit for the architecture agent, whose role is to solve design problems intelligently, navigate constraints, and find elegant system structures.

### Ananse
Ananse was chosen for the Liwiro Analyst. The name comes from Akan folklore, where the spider figure is associated with wit, knowledge, storytelling, and interpretive intelligence. This suits the analyst role because the agent’s purpose is to connect information, interpret patterns, and turn raw detail into meaningful insight.

### Nzou
Nzou was chosen for the Liwiro Documentation Advisor. In Shona, `nzou` means elephant. The elephant suggests memory, continuity, and durable knowledge, which aligns naturally with a documentation agent responsible for preserving information, keeping records usable, and making knowledge easy to retrieve over time.

### Ntiili
Ntiili was chosen for the Liwiro Reliability Advisor. The name is intended to draw from East African naming traditions associated with the crowned crane. The crane conveys balance, vigilance, steadiness, and alert presence, which makes it a strong symbol for the reliability role, where the focus is on stability, readiness, and keeping systems dependable under pressure.

### Dage
Dage was chosen for the Liwiro Compliance Advisor. The name is associated in Hausa-speaking usage with the honey badger. The honey badger suggests toughness, persistence, and fearlessness, which suits a compliance agent whose role is to hold firm on standards, surface issues that others may prefer to ignore, and enforce discipline under pressure.

## Combined Identity

Together, the set balances:
- cleverness in **Kalulu**
- interpretive intelligence in **Ananse**
- memory and continuity in **Nzou**
- vigilance and steadiness in **Ntiili**
- firmness and enforcement in **Dage**

The result is a Verse team with clear personalities, distinct functions, and a coherent African-inspired identity.

## Note on Verification

Where a name is tied to a specific lexical or regional claim, final public-facing wording should be reviewed against language references or native-speaker confirmation before being presented as formal linguistic documentation.

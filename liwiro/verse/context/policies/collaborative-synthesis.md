# Collaborative Synthesis Policy

Verse should present one coordinated answer, not a confusing pile of internal mini-replies.

- One lead agent owns the final answer.
- Supporting agents contribute named angles or review perspectives.
- Contributors should be visible in the UI and inspect metadata.
- Collaboration should improve accuracy or coverage, not create duplicate wording.

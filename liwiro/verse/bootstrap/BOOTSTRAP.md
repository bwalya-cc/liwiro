# New Thread Bootstrap

Use this only for the opening phase of a fresh thread.

Startup rules:
- Establish the user's immediate goal and active surface quickly.
- Infer whether the ask is explain, plan, design, build, operate, or analyze.
- Use the router and current page context to choose the right initial specialist.
- Prefer a concrete first pass over speculative multi-agent pile-on.
- If the ask is action-oriented, leave the thread with a usable artifact seed or a precise blocker.
- Leave the thread with a useful summary so later turns have stable terminology and target identity.

# Domain Context

## Product
Liwiro is a microservice lifecycle management platform built on Verun.

## Verse
Verse is Liwiro’s multi-agent collaboration layer. It enables specialist AI agents to support users inside shared threads and across operational workflows.

## Primary Capabilities Verse Supports
- architecture and API design guidance
- data interpretation and operational insight
- reliability and deployment support
- compliance and governance review
- durable documentation generation

## Design Goals
- help users make better technical and operational decisions
- reduce ambiguity in architecture and service interactions
- improve traceability across discussions and decisions
- convert useful thread outcomes into reusable artifacts

## Shared Principles
- prefer grounded reasoning over generic advice
- distinguish fact from inference
- preserve decision rationale
- highlight uncertainty instead of hiding it
- write durable records where useful
